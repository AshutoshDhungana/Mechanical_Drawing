# Extracted workbook data (Phase 0)

Generated by `python tools/extract_workbook.py` from `Vertical-Lift-Gate.xlsm`. Don't hand-edit these files; re-run the script instead. It needs `pip install openpyxl`.

## `tables/`: lookup data

Every file records its `source` cell range and `units`. Values are kept in the workbook's own units, so converting to SI is a job for the calc engine.

| File | Contents | Used by |
|---|---|---|
| `ismb.json` | ISMB 100–600 beam properties (IS 808) | Wheel Design, Embedded Parts |
| `ismc.json` | ISMC 75–400 channel properties, plus connection details | Embedded Parts |
| `gate_shapes.json` | `ShapeData`: each ISMB as a 3-plate shape in metres, with area and Zx | Define Beam, Wheel Design, Embedded Parts |
| `ismc_lib.json` | Duplicate ISMC subset | hidden `Embedded` only |
| `rope_6x37.json` | 6×37 wire rope: mass and minimum breaking force by grade/core. **Has `errata`** | Hoist(Rope Drum) |
| `rope_6x37_old.json` | `RopeData` (Sheet3): the same table in kg/100 m | hidden `Rope Drum Hoist` only |
| `steel_grades.json` | IS 2062 E250–E650: UTS, and yield by thickness band | not referenced by any formula |
| `anchor_bolts.json` | Anchor bolt size / length / unlabelled column AC | Embedded Parts |
| `plate_coefficients.json` | Skin-plate bending coefficients: `CCCF` (edge panels) and `CCCC` (inner panels) vs b/a | Stress |
| `lists.json` | Dropdown sources: beam/gate types, friction, ballast, corrosion allowance, bolt sizes, spacing methods, rounding steps, gear modules, motor kW | various |

## `golden/`: reference results

- **`workbook.json`** has every non-empty cell on all 24 sheets: 12,259 cells and 7,017 formulas. For each cell it stores the cached value `v`, the formula `f`, the number format `fmt` (which carries units such as `"kN/m2"`), and `in: true` when the cell is unlocked (an input). It also holds the 92 named ranges. The values are what Excel saved on 2023-08-18, and these are the golden values the calc engine must reproduce.
- **`inputs.json`** lists the 266 editable cells, each with its row label, value, unit, formula (when the default is computed) and data validation. This is the starting input list for the UI.

## Findings from the cross-checks

The script prints these each time it runs.

1. **Two typos in the active rope table**: 52 mm 1770-CWR is `11524` kN (should be 1524), and 64 mm CF mass is `14.71` kg/m (should be 14.17). Both were confirmed against Sheet3 and the d² trend. The rows keep the workbook values so golden tests still match; the corrections are in `rope_6x37.json` → `errata`. The saved design uses 28 mm rope, so the golden values aren't affected.
2. **Sheet3 has its own typos**: 16 mm 1770-CWR is `114` (should be 144) and 38 mm 1960-CWR is `301` (should be 901). Only the hidden legacy hoist reads Sheet3.
3. **`gate_shapes` matches ISMB exactly**, with web depth = h − 2·tf.
4. **Plate coefficients are stored ×0.0254**, and the Stress formulas checked divide by 0.0254 again, so the factor cancels in those. This is left over from the imperial original. The app should use the `raw` (textbook) coefficients, drop both factors, and confirm each use during Phase 1.
5. **The anchor bolt size labels are wrong** (an Excel fill-series accident: M24, M25, M26, M27…). The lookup formulas address the table by row block, so `size` is taken from the block and the original label is kept as `sheet_label`.
6. **31 cached `#DIV/0!` errors**: 15 on Beam Spacing (row 21, columns AJ–AW) and 16 on Wheel Spacing (row 16, columns AB–AT). They sit in the side grid that solves the continuous-beam moments, where a span of zero is divided by. No other cell shows an error, so they don't spread into the results. The app should guard that division.
7. **Some cells still carry imperial or odd units**: SecProp I4/U4 have leftover `psi` number formats, `Rope Drum Hoist` takes its load in `Ton`, the hoist motor power is in `HP`, and `Mpa` is spelled that way. Review these in Phase 1.
8. There are 110 defined names in total: the 92 used by calculations plus 18 sheet-local print areas and print titles, which are omitted.
